# 内容系统：素材池、模板、查重

## 四层素材池与抓取方法

| 层 | 来源 | 抓取方法 | 失败降级 |
|---|---|---|---|
| L1 个人语录 | 语录库.md + 当日对话 | 用户说「记到素材池」即追加原话；早班先读全库 | 永远优先；不足时进展帖顶上 |
| L2 中文热点 | 知乎热榜、B站/小红书 | 知乎官方 Zhihu CLI / OpenCLI / RSSHub；均不可用 → WebSearch「AI 热点 中文圈」 | 该层减产并在草稿箱标注 |
| L3 AI 资讯 | HN、GitHub Trending、Product Hunt、卡兹克等博客 | HN：`https://hn.algolia.com/api/v1/search?tags=front_page&hitsPerPage=15`；GitHub：WebFetch `github.com/trending` | 减产并标注 |
| L4 XHunt 爆帖 | 用户 Chrome 的 XHunt 面板 | computer-use 读 x.com/home 右栏「AI 实时热门」：推文榜（带分数）+ KOL 榜 + 热门标签 | 退回 x.com/explore 热点 |

抓素材不照抄：每条素材进草稿必须接上 vill 自己的判断，否则弃用。

## 与 vill-original-content-workflow 的分工（硬路由）

- **原创观点帖、进展帖、thread（每日 3+2+1 条）**：必须经 `vill-original-content-workflow`，不可跳过。
  - 短帖走轻量版：输入分流 → 阶段 2（把问题搞懂，只检索 3 篇内资料）→ 阶段 4（个人证据）→ 阶段 7（`/dbs-ai-check`）；跳过对标与传播元素阶段。
  - thread / 长文改写走完整流程（含 `/dbs-content` 组织与 `/dbs-content-risk-check`）。
  - 语料入口：语录库 + 当天对话与项目记录；没有个人证据的观点不产出。
- **热点短评、AI 资讯、引用帖（每日 4+3+2 条）**：素材驱动，不强制走工作流，但必须满足文风规则且接上 vill 的判断；拿不准算不算「原创」时，按原创处理（走工作流）。

## 六类帖模板（每日 15 条配比）

1. **原创观点 ×3**（L1）：判断先行 → 具体场景 → 一句收束。开头可用「很多人以为…其实…」「真正的 X 是…」。
2. **热点短评 ×4**（L2/L4）：事件一句 → 判断一句（→ 边界一句）。≤140 字，快而锋利。
3. **AI 资讯 ×3**（L3）：它是什么 → 对普通人意味着什么 → 我会怎么用/不用。禁止纯转述。
4. **引用帖 ×2**（L4）：quote 爆帖 + 一句增量观点，不复述原文。
5. **进展帖 ×2**（L1）：自我开源「问题 → 原判断 → 实操 → 失败/修正 → 结果」。必须当天真实在做的事。
6. **短帖/thread ×1**：现象级观察短帖，或公众号长文改 5–8 推 thread（隔日排）。thread 首帖独立成立。

## 文风规则

- vill 语气：判断先行，短句，具体到「谁在哪一步卡住」；最多 1 个 emoji，多数时候不用。
- 观点可追溯：语录库 / 用户确认过的判断 / 当天真实事件，三者无其一则弃用。
- 禁止：均匀排比、万能结论、「在这个时代」「毫无疑问」、四面光的骑墙话、假完整（列满 3 点装深度）。
- 有立场，敢留破绽；同一主题可以连发，形成连续剧效应。

## 查重

- 发布前与 `复盘/发布日志.md` 近 30 天逐条比对。
- 复盘黑名单中的句式、话题不再使用（黑名单由 review-loop.md 维护）。
- 引用过的爆帖 7 天内不再 quote（回复不受限）。
