# vill-twitter-autopilot

vill 的推特自动运营系统。四层素材池（个人语录/中文热点/AI 资讯/XHunt 爆帖）产出每日 15 条帖子，XHunt 热榜产出每日 30 条回复（分早中晚三批），写入 Obsidian 本地草稿箱待审，用户放行后经浏览器排期发布，每晚数据复盘并调整次日配比。用户说「推特早班」「推特午班」「推特晚班」「推特复盘」「放行推特」「记到素材池」「推特诊断」时使用。

## 安装

```bash
npx -y skills add tieka055-debug/vill-twitter-autopilot -g --all
```

## 使用

安装后，可以这样开始：

> 使用 $vill-twitter-autopilot 完成它所解决的任务。

## 运行依赖

- 支持 Agent Skills 的客户端
