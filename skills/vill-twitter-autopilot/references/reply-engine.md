# 回复引擎：每日 30 条

## 数据源

XHunt 面板（用户 Chrome，x.com/home 右栏）：
- 推文榜 / 飙升榜：每小时阅读量上升最快，带分数
- KOL 榜：博主排名 + 粉丝数 + 代表帖分数
- 热门标签：超级个体、vibe coding 等（话题风向）

每批回复生成前**实时抓一次面板**，不用上一批的旧数据。

## 选帖标准（优先级）

1. 飙升榜 / 推文榜分数 ≥60 的中文 AI 圈帖，发布 ≤3 小时，回复 <50（还在窗口期）
2. KOL 榜博主的最新帖（≤1 小时）
3. 话题与 vill 方向强相关：AI 工作流 / AIGC / 普通人用 AI

避开：纯新闻通稿、钓鱼引战、饭圈互撕、广告。

## 批次

早 10（9:00–11:00 贴）/ 午 10（13:00–15:00）/ 晚 10（20:00–22:00）。
同一帖下只回 1 条；同一作者每天最多回 2 条；不连回自家引用过的帖子作者超过 2 天。

## 增量四型（每条回复必须命中其一）

1. 补充一手数据 / 亲身经历
2. 给一个可立刻操作的做法
3. 指出边界：「什么情况下这招不成立」
4. 有礼貌、有依据地反驳

## 禁止

- 空捧：「说得好」「学到了」「太真实了」「收藏了」
- 带链接引流；同一次对话里提自己超过 1 次
- 长过 3 句；书面腔（「综上所述」「值得一提」）

## 输出格式（草稿箱回复区）

```
### 早批（9:00–11:00）
1. ⚠️ @handle ｜原帖：《标题/一句话摘要》
   回复：{1–2 句}
```
⚠️ = 只读到标题、未读原文，贴前必须点开原帖核对；核对后删掉 ⚠️。
