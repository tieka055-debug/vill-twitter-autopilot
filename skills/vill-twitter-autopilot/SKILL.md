# Vill 推特自动运营系统

账号：**@vill1y**（用户 Chrome 已登录，XHunt 插件装在该 Chrome）。
方向：AI / AIGC / 工作流。定位母题：普通人如何用 AI 创造收入；先做作品，不做导师。
每日循环：抓素材 → 产帖与回复 → 草稿箱待审 → 放行发布 → 复盘调权重。

## 指令表（三班制，无审核：X 草稿箱就是审核面）

| 用户说 | 动作 |
|---|---|
| 推特早班 | 抓四层素材 → 产 15 帖 → **push_batch.mjs 批量直灌 X 原生草稿箱** → 汇报 |
| 推特午班 | 抓 X 热帖全文 → 生成 10 条回复 → **自动回复**（间隔 50 秒）→ 汇报 |
| 推特晚班 | 自动回复 10 条 → 记录当日各帖数据 → 归因 → 调整明日配比 |
| 推特复盘 | 近 7 日归因 → 配比与黑名单（见 references/review-loop.md） |
| 记到素材池：{内容} | 原话追加进语录库，不改写 |
| 推特诊断 | 流量连续低迷时触发算法与爆帖规律调研（见 references/review-loop.md） |

## 状态文件（Obsidian 库根：/Applications/vill自媒体知识库/vill自媒体知识库）

- 语录库：`推特运营/素材池/语录库.md`
- 每日存档：`推特运营/草稿箱/YYYY-MM-DD.md`（当日已灌条目清单）+ `YYYY-MM-DD-回复清单.md`
- 复盘与发布日志：`推特运营/复盘/`（发布日志.md 为查重依据，滚动保留 30 天）

## 每日数值与配比

帖子 **25 条/日**（直灌草稿箱，用户自挑自发）= 原创观点 5 + 热点短评 7 + AI 资讯 5 + 进展帖 3 + 短帖 2 + 观点长帖 2 + 进展/连载 1。
回复 **30 条/日**（全自动）= 早 10 + 午 10 + 晚 10，条间 ≥40 秒；单日上限 30，宁少勿多（风控）。
发布节奏：草稿箱自然堆积，用户全天随刷随发；AI 不点发布。

## 硬规则

0. **原创类帖子（原创观点/进展/thread）必须经 `vill-original-content-workflow`**（短帖轻量版：搞懂→个人证据→ai-check；thread 全流程），见 references/content-system.md 的硬路由。

1. **AI 只灌草稿箱，永不点发布**；发布权 100% 在用户手里。不自动点赞、不自动关注、不自动私信。
2. 每条与发布日志近 30 天查重：同观点同角度弃用，同观点换角度可发。
3. 语录库原话只提炼不改意思；无个人证据支撑的判断必须标注素材来源。
4. 回复必须有增量（一手经历/可操作做法/边界反驳），禁止空捧；未读原文只读到标题的回复标 ⚠️，贴前须点开原帖核对。
5. 单帖 ≤ 280 字符（中文按 2 计）；thread 首帖必须独立成立。
6. 出现连续 0 展示等疑似限流信号 → 停发，报告用户，不自行重试。

## 文风速查

判断先行、短句、说人话；每帖只讲一个点；禁排比堆叠、万能结论、「在这个时代」类空话。详见 references/content-system.md。

## 停止条件

≥3 层素材抓取失败 → 降配产出（如 8 帖）并在草稿箱标注缺层；
用户未放行 → 不催促不重试，次日早班汇报草稿状态。
